GITHUB PAR UPDATE KAISE DAALEIN
1. Repository me "app" folder dobara upload karo (purani files replace ho jayengi).
2. .github/workflows/build.yml ko naye build.yml se replace karo (file kholo > pencil > paste > Commit).

EK BAAR KA SIGNING SETUP (sirf pehli baar)
A. Repo ko PRIVATE karo (Settings > General > Danger zone > Change visibility).
B. Actions tab > "Build APK" > Run workflow > mode = keystore, password = koi 8+ letters/numbers likho > Run.
C. Run khatam hone par neeche Artifacts me "msgsaver-keystore" download karo. Zip me:
     msgsaver.jks          -> ise Google Drive/pen drive me SAFE rakho (gum hui to update nahi de paoge)
     keystore_base64.txt   -> iska poora text copy karo
D. Repo > Settings > Secrets and variables > Actions > New repository secret. 4 secrets banao:
     KEYSTORE_BASE64   = keystore_base64.txt ka text
     KEYSTORE_PASSWORD = wahi password jo step B me likha
     KEY_ALIAS         = msgsaver
     KEY_PASSWORD      = wahi password
E. Actions me run ke Artifacts ka "msgsaver-keystore" DELETE kar do (trash icon).
F. Repo ko wapas PUBLIC karo (taaki website se download aur app ka update check chale).

1. app/build.gradle.kts me versionCode ko 1 se badhao (2 -> 3 -> 4) aur versionName badlo.

   https://github.com/coding-world197/MsgSaver-apk/releases/latest/download/ChatRewind.apk

v1.5 (build 6) - New Photos tab (regular photos/videos people send you, not view-once).
Each saved status, voice note and photo now shows a small "WhatsApp" or "Business" tag,
so you can confirm both accounts are being picked up.
v1.6 (build 7) - Fixed repo name mismatch: Updater now points to coding-world197/MsgSaver-apk

v1.7 (build 8) - Removed the Photos tab and its scanning. App is back to Messages, Status, Voice, Settings.

v1.8 (build 9)

v1.9 (build 10) - Instagram DMs are now saved too, the same way WhatsApp messages are.
Messages tab has a "Both apps / WhatsApp / Instagram" filter, and each message shows a small
💬 or 📸 icon. Important: Instagram doesn't send a "message deleted" notification, so deleted
Instagram DMs can't be flagged the way deleted WhatsApp messages are — only what was saved
before deletion stays visible.

v2.0 (build 11) - New "Reels" tab: paste a public Instagram Reel/post link to download its
video. Only works for PUBLIC accounts; private accounts and Stories are not accessible this
way. This depends on Instagram's page structure and may stop working if Instagram changes it.

v2.1 (build 12) - Reels downloader now tries Instagram's "embed" page first, which stays
static HTML without needing login, instead of the regular post page (which often needs
JavaScript/login to render and returned nothing). More fallback patterns added too.
