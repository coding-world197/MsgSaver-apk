ChatRewind - run guide
1. Android Studio (Koala 2024.1 ya naya) install karo: developer.android.com/studio
2. File > Open > ChatRewind folder. "Sync" hone do (internet chahiye, pehli baar 5-10 min).
3. Phone: Settings > About phone > Build number 7 baar tap > Developer options > USB debugging ON.
4. Phone USB se jodo, Android Studio me upar Run (green play) dabao.
5. App kholo > Settings tab > teeno cards (Notification, Folder, Battery) ko ✅ karo.
6. Test: dost se message bhejwao, delete for everyone karwao > Messages tab > Deleted.
7. APK banane ke liye: Build > Build Bundle(s)/APK(s) > Build APK(s).
